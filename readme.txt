FUNGSI (FUNCTION) DI PYTHON
1. Apa itu Fungsi?
   - Blok kode terstruktur yang dibuat untuk menjalankan tugas tertentu.
   - Bisa dipanggil berkali-kali sesuai kebutuhan tanpa harus menulis ulang kodenya.

2. Keuntungan Menggunakan Fungsi
   - Mengurangi pengulangan kode (nggak capek nulis ulang).
   - Membuat program jadi jauh lebih terstruktur dan rapi.
   - Kode lebih gampang dibaca dan dipahami.
   - Lebih mudah saat proses perbaikan/debugging jika ada error.
   - Program yang ukurannya besar bisa dipecah jadi bagian-bagian kecil (modular).

3. Struktur Dasar Fungsi di Python
   - def  : Keyword utama buat bikin/mendefinisikan function.
   - nama_fungsi : Identitas atau nama dari function yang dibuat.
   - ()   : Tempat untuk menaruh parameter (bisa kosong atau ada isinya).
   - :    : Tanda awal mulainya blok kode di dalam fungsi.

   Contoh format:
   def nama_fungsi(parameter):
       # blok kode di sini

4. Parameter pada Fungsi
   - Digunakan buat ngirim data atau nilai dari luar ke dalam fungsi.
   - Satu fungsi bisa punya lebih dari satu parameter (dipisah pakai koma).

5. Return Value
   - Digunakan untuk mengembalikan nilai hasil proses dari dalam fungsi ke luar pemanggilnya.
